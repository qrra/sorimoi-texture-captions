# 소리모이 · 소리가 되는 글자 0.4.0

**영상의 재생 시간에 대사와 소리를 연결하는 Chrome/Whale 확장 미리보기입니다.** 큰 배경 박스를 없애고, 충격음은 작은 글자 한 단어로 잠깐 커졌다 돌아옵니다. 정확도·범용성이 검증 완료된 제품은 아닙니다.

## 0.4.0 첫 재생 자막과 Mac 가속

- Apple Silicon Mac에서 선택형 MLX Whisper 로컬 서비스를 실행하면 탭에서 캡처한 오디오 구간을 우선 분석합니다. 서비스가 없거나 요청이 실패하면 기존 브라우저 Whisper가 이어받습니다.
- 인식 결과를 원본 시각에 맞춰 저장하면서, 가장 최근 대사도 첫 재생 중 오버레이에 잠시 표시합니다. 분석 지연만큼 자막이 늦게 보일 수 있으며, 준비된 자막 구간 다시 보기는 계속 사용할 수 있습니다.
- 기본 자막 글자 크기를 30% 키우고, 확장 팝업의 **자막 글자 크기** 슬라이더로 80~180% 범위에서 조절할 수 있습니다. 실행 중에도 바로 적용됩니다.
- 노래방식 단어 하이라이트에 발화 구간의 오디오 RMS를 연결해 단어마다 글자 크기가 94~106% 범위에서 살짝 달라집니다. 추가 오디오 분석을 기다리지 않고, 기존 캡처 오디오에서 측정합니다.
- **자막 포인트 색**에서 사용자가 고른 색을 현재 단어와 주변 발광 효과에 적용합니다.
- 사용자가 보낸 헤드폰 오소리 이미지를 16·32·48·128px 확장 아이콘으로 적용했습니다.
- 기존 자막 우선, 효과음 분류, 텍스처 애니메이션과 확장 팝업 UI는 유지합니다.

## 설치와 사용

1. 설치 ZIP을 압축 해제하고 `manifest.json`이 바로 있는 `sorimoi-chrome` 폴더를 Chrome/Whale 확장 관리의 개발자 모드 → 압축해제된 확장앱 설치로 선택합니다. 기존 같은 폴더가 설치되어 있으면 확장 관리에서 새로고침합니다. 이름 **소리모이 · 소리가 되는 글자**, 버전 **0.4.0**을 확인하세요.
2. YouTube Shorts나 영상을 재생하고, 확장 아이콘 → **자막 시작**를 누릅니다.
3. 기존 YouTube 자막을 사용할 수 있으면 자동으로 켭니다. 원래 글자·시간을 유지하고 배경과 크기만 작게 정리합니다. 자동 번역·의미 재작성은 하지 않습니다. 기존 자동 자막의 오류까지 고치는 기능은 아닙니다.
4. 기존 자막이 없으면 첫 재생 중 로컬 Whisper가 단어별 시간을 분석합니다. 인식된 가장 최근 문구는 도착 시점에 영상 위에 표시하고, 준비된 구간은 원본 영상 시간에 연결합니다. **준비된 자막 구간 다시 보기**를 선택하면 원래 시점에 맞춰 다시 볼 수 있습니다. 쇼츠가 매우 짧거나 음악·겹친 말소리가 있으면 인식 결과가 없거나 틀릴 수 있습니다.
5. 충격은 32ms PCM 블록의 급격한 변화로 감지합니다. 처음 약 200ms는 연결 잡음을 피하는 준비 구간입니다. 처음 듣는 충격의 쿵·탁·쾅은 파형의 질감 표현입니다. 문·박수·개 등 사물을 확정한 뜻이 아닙니다. 강한 대사·음악·숨소리가 지배하는 구간은 억제하지만 오탐·누락은 남습니다.
6. YAMNet은 약 0.975초 창의 소리 종류 후보를 구합니다. 충격 분류가 늦게 오면 원래 충격 시각과 함께 저장하고 다음 반복에 표현합니다. 같은 창에 여러 충격이 있으면 종류 연결이 틀릴 수 있습니다. 지속음은 같은 계열이 연속 확인되고 최근 입력과 일치할 때만 바스락·찰랑·후우 등을 표시합니다. 모호한 결과는 생략합니다.
7. 다음 쇼츠로 이동하면 이전 영상의 결과를 비웁니다. 같은 영상의 탐색·배속·반복에는 원본 시간 기반 대사와 준비된 효과음을 연결합니다. 새 페이지·새 탭에서는 다시 켜주세요.
8. **자막 끄기**로 오디오 캡처·Worker·원래 자막에 넣은 스타일을 정리합니다. 움직임·강도 설정은 끄고 다시 켜면 적용됩니다. OS의 모션 줄이기를 존중합니다.

## 분석 속도와 구성

Apple Silicon 사용자는 [선택형 MLX Whisper 로컬 가속 경로](docs/macos-fast-asr.md)를 설치할 수 있습니다. 확장은 현재 탭에서 이미 캡처 중인 오디오의 짧은 구간만 `127.0.0.1`로 보내며, 서버는 외부 네트워크 인터페이스에 열리지 않습니다. 기본 모델은 Whisper base이며, `whisper-tiny-mlx`로 바꾸면 더 빨라질 수 있지만 인식 오류도 늘 수 있습니다. 첫 모델 다운로드와 첫 로딩에는 추가 시간이 듭니다.

실시간 첫 재생 경로는 전체 영상 다운로드, Demucs 분리, WhisperX 2차 정렬, ASS 생성·SubtitlesOctopus 렌더링을 사용하지 않습니다. 이 프로젝트의 기존 YAMNet 효과음 분류와 브라우저 fallback을 유지하면서 대사 분석 구간만 MLX로 가속합니다. 고정된 처리 시간이나 한국어 인식 정확도를 보장하지 않습니다.

## 세 가지 기준과 구현

| 기준 | 0.3 구현 | 남은 한계 |
|---|---|---|
| 대사 싱크·해석 | YouTube 원래 자막 우선, 브라우저 또는 MLX Whisper 단어 타임스탬프, video.currentTime 기반 표시 | 인식 결과가 오디오보다 늦게 도착할 수 있고 한국어 오인식은 남음 |
| 소리 구분 | YAMNet 계열 점수·다른 계열과의 차이·음성/음악 억제, 같은 종류 연속 확인 | 분류 점수는 보정된 확률이 아니며 모든 소리 지원·정확도 보장 아님 |
| 글자 표현 | 배경 없는 한 단어, 쾅의 짧은 확대·눌림, 바스락의 미세 떨림, 물소리의 완만한 퍼짐 | 합성 효과를 촉감 자체의 측정으로 해석하지 않음 |

시간은 오디오 수집 시각·영상 시간·결과 도착 시각을 구분합니다. 180ms 이상 늦거나 다른 영상 세대에 속한 실시간 효과는 버립니다. 이 제한은 180ms 이내의 정확도를 보증하는 수치가 아닙니다.

## 노션 후보 재검토와 선택

[소리모이 노션](https://app.notion.com/p/404b2cbd917a8101b616e5f05d9e9f1d)의 텍스트 추출·시간 검출 후보와 각 공식 문서를 다시 확인했습니다. 노션의 사전 분석 MVP보다 이번 사용자의 범용 쇼츠·반응형 표현 요청을 우선했습니다.

- **WXT + vtt.js + YAMNet**은 기존 브라우저 설치·cue 파싱·가벼운 분류 기반으로 유지했습니다. 브라우저 Whisper/Transformers.js와 옵션인 MLX Whisper가 같은 단어 타임스탬프 schema를 씁니다. 정확히 세 라이브러리만 넣는 것을 성능 목표로 삼지 않았습니다.
- [youtube-transcript-api](https://github.com/jdepoix/youtube-transcript-api): 기존 자막의 text/start/duration 확보에 유용하지만 Python 프로그램이며 차단·자막 미제공 가능성이 있습니다. 이번 확장에 Python 서버를 요구하지 않도록 넣지 않았습니다. YouTube 화면의 원래 자막을 활용하며, 임의 영상 자막 다운로드가 보장된다고 주장하지 않습니다.
- [MLX Whisper](https://github.com/ml-explore/mlx-examples/tree/main/whisper): 선택형 macOS arm64 로컬 서비스에서 짧은 탭 오디오를 단어 시각과 함께 처리합니다. 전체 영상을 다시 내려받지 않으며, 첫 실행은 모델을 받아옵니다. 브라우저 Whisper는 fallback으로 유지합니다.
- [PANNs DecisionLevelMax](https://github.com/qiuqiangkong/audioset_tagging_cnn): 프레임 단위 소리 검출을 제공하지만 PyTorch 환경·별도 체크포인트가 필요합니다. 노션에 가중치 재배포 허가 미확인으로 기록되어 있어 이번 브라우저 배포에 넣지 않았습니다. 실제 비교 실행을 하지 않았으므로 YAMNet보다 좋다고 판단하지 않습니다.
- [CLAP](https://github.com/LAION-AI/CLAP), [BEATs](https://github.com/microsoft/unilm/tree/master/beats): 소리 유사도·표현/분류 후보이며 기본 출력만으로 정밀한 발생 시각을 해결하지 않습니다. 이번 지연 경로에 추가하지 않았습니다.

팀원의 [OnSori](https://github.com/NY-colab/onsori-youtube)를 사용 흐름 참고로 삼았습니다. 코드를 복사한 파생 빌드는 아닙니다. 녹음 후 완료 결과를 표시하는 문제를 피하려고 대사·종류 분석·즉시 충격 반응을 각각 다른 시간 경로로 처리합니다.

## 검증과 재현

`npm test`, `npm run extension`으로 테스트·확장 빌드를 실행합니다. 모델과 WASM이 없는 소스 ZIP은 `npm ci`, `npm run setup`이 먼저 필요합니다. 선택형 Mac 서비스는 `requirements-macos-asr.txt`와 [실행 안내](docs/macos-fast-asr.md)를 참고하세요. 검증 세부 결과와 미검증 범위는 **VERIFICATION-0.4.0.md**를 보세요.

설치본에는 기존 브라우저 Whisper·YAMNet·WASM이 포함됩니다. 마이크를 사용하지 않습니다. 기본 모드는 캡처 오디오를 네트워크로 보내지 않으며, 사용자가 선택형 Mac 서비스를 실행할 때만 짧은 오디오 구간을 로컬 `127.0.0.1`에 전송합니다. 정확한 첫 재생 ASR, 모든 소리의 구분, 모든 사이트·사용자 프로필의 정상 동작은 보장하지 않습니다.
